# Argument groups of indexed recursive calls

Status: local research iteration. No blog post or public deployment.

## Rule

The recursive-index collar now has an argument-group selector. Parameters,
motives, branch methods and indices use the same ordered ports, argument-slot
labels, paging controls and kernel-schema navigation. The major premise keeps
its own port. A group with zero arguments is disabled explicitly.

The partition comes from the recorded recursor metadata and the literal
application spine of the recursive schema call. Parameters, motives and methods
in the supported unchanged-self-recursion pattern forward their corresponding
rule binders. Every port retains the native-record hash, source query/minor,
reduction-schema root and exact occurrence route. A schema argument is not an
additional source-proof occurrence or a claim of mathematical necessity.
Recorded binder names label the prefix ports; names never determine their
identity, order or lexical target.

The call's constant head retains its exact universe-level payload and a separate
`LevelDAG/1` representation. An empty payload is recorded explicitly as
monomorphic. Level arguments are not Expr arguments and do not shift the
parameter/motive/method/index slots.

The collar still has at most eight vertices and seven wires, including at most
four arguments of the selected group. Visible plus hidden ports account exactly
for that group; the full partition also accounts for the major premise. Selecting
a schema port opens the existing 32-vertex cut, with reversible folding, exact
retained/hidden occurrence accounting and visible lexical references. Hidden
structure remains a boundary. Selecting a different group resets its window;
changing the method disposes the collar and its kernel viewport.

Prefix-group code loads optionally. A failed load preserves the existing index
view, and a delayed load cannot restore an obsolete method selection. The
original proof selection stays fixed during schema navigation.

## Fresh native controls

Four authored Lean 4.33.1 declarations add eight kernel-checked method frames:

- A vector with one type parameter has recursive index argument 5, following
  one parameter, one motive and two branch methods.
- A family with five dependent parameters `A, B, a, b, tag` has recursive index
  argument 9. Here `A : Type u`, `B : A → Type v`, `a : A` and `b : B a`.
  The fifth parameter crosses the four-port window. The domains of `B`, `a`
  and `b` refer to earlier parameter binders, with exact lexical routes.
- A parameterized functional family has
  `children : (k : Fin (size a)) → Fan A size k.val`. Its recursive index
  references the outer parameter `size`, constructor field `a` and the local
  family variable `k` at distinct schema routes.
- An indexed proposition has a recursive proof premise and no universe
  arguments. This tests an empty constant-level payload independently of the
  polymorphic data controls.

Lean supplies each declaration's kind and level-parameter names directly. The
proposition is a theorem; the other three are noncomputable definitions because
this compiler does not emit those recursors directly. Declaration typing,
reduction-rule observations and computed eta-method interfaces were checked in
the kernel. No executable-code benchmark is claimed.

The environment imports Mathlib/Aesop, with private Riccati modules absent. The
cache has verified binary hashes and attribution to Mathlib revision
`0df444a360eaa60ab8c11dca51a86af692955474`; original Git checkouts and an independent
dependency rebuild are not verified. Public assets contain compiled packets and
native observations, not original private project proof scripts. These authored
controls remain separate from the main proof corpus and AI-attributed sample.

## Limits

This extension covers argument groups of the recorded indexed unchanged-self-
recursion pattern, including the finite parameterized controls above. Mutual
recursion, changing recursive parameters and arbitrary recursor schemes remain
outside this rule. It does not normalize or compare index values, infer proof
strategy or premise necessity, reconstruct tactics or measure comprehension.
Source-path/page/memo limits and the fully resident 8 MiB selected native-call
limit remain unchanged; diagram bounds are not whole-browser heap bounds.

The eight recorded Riccati methods keep their original constructor-field roles.
They acquire no invented recursion, index ports or parameter coverage. AI-source
attribution and unavailable-candidate coverage remain those of the earlier
frozen dataset. No general elimination or massive-AI-proof adequacy claim follows.
