Visual notation manual · Checks and limits

Equality transport moves a value between fibers of a family. In the kernel, a motive may depend on both the endpoint and the equality witness:

\[ C : (b:A)\to(a=b)\to\mathrm{Sort}_v,\qquad p:C(a,\mathrm{refl}_a),\qquad h:a=b, \qquad \mathrm{Eq.rec}(p,h):C(b,h). \]

For Eq.ndrec, the family ignores the witness. Eq.mp transports between equal types; Eq.mpr uses the reversed equality. These wrappers are expanded by a bounded, kernel-checked template. The square represents typed transport, not a branch in a proof or a recovered tactic.

Load one original native query and its source pages. Retained source paths: at most 4,096 rows; fetch cache: 256 rows. The selected computed graph loads fully within its own limit.

Trace source inputs switches the square to a three-box construction collar. Solid connectors follow exact source arguments; dashed connectors pass through recorded local bindings. Dotted boxes are context inputs. Each port retains its ordered argument slot, producer context, checked type conversion and original occurrence. Nondependent bindings keep their flag; a connector records their source value and a checked closed binding conversion, rather than claiming a recovered tactic. Fragments can overlap, so their sizes are not additive. Composition checks and limits.

Click a value or equality card for its exact original route. Click an endpoint or family for its separate computed address. Further applications remain distinct from the transport core: several selected occurrences can refer to the same source core.

The records cover a finite candidate inventory and authored controls. Unsupported candidates retain their reasons. This rule does not establish semantic proof compression, complete Lean coverage or improved human comprehension.

Application inputs beyond transport

An ordinary application has a function field and an ordered sequence of actual arguments. The arguments include types, instances and proofs supplied by elaboration. These are compiled expression fields; they do not reconstruct the original surface syntax or tactic script.

\[ f : \Pi(x_1:A_1)\cdots(x_n:A_n),R,\qquad f\,a_1\cdots a_n : R[a_1/x_1,\ldots,a_n/x_n]. \]

The view retains one function port and at most four argument ports at a time. It marks proof, type and value roles separately from explicit, implicit, strict implicit and instance binder visibility. A callable result is a function-typed result, not evidence that the source call is missing an argument.

Solid connectors denote the selected source fields. A dashed first segment follows a recorded local binding. The separate type-reference list refers to bound variables in the literal function-type telescope, with a native checked instantiation bridge. It does not infer which argument values are used, which premises are necessary, or the mathematical strategy. An unavailable literal type prefix remains marked.
