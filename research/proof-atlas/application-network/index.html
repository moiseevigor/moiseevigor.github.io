Compose applications through source uses

A function application has a result and ordered inputs. If an input's source producer is another recorded application occurrence, the two figures can share that result box. Each destination port remains separate. A local-definition path stays explicit.

This experiment covers 162 recorded application occurrences and 787 actual input positions, with 101 application-to-application uses. It includes 87 Riccati applications and 68 uses. The other 686 inputs remain context, unrecorded-fragment or definition boundaries; they are not omitted arguments. This selected inventory is not the complete Riccati proof.

The composition rule

$$\begin{gathered}\text{producer occurrence }p\;\xrightarrow{\text{ordered input }j}\;\text{consumer occurrence }c\\\Gamma_p\vdash p:A,\qquad\Gamma_c\vdash a_j:B\\\text{recorded source-use path }a_j\rightsquigarrow p,\quad\Gamma_p\preceq\Gamma_c\end{gathered}$$

The native observations already check the input domain, context extension and type conversion. The new derivation also compares the producer's type with that same occurrence's result type in its original context. Names, equal types, proof conversion and shared storage do not select the endpoint. An arrow records a source use; it does not assert that a premise is mathematically necessary.

Solid lines represent direct source fields. A dashed line passes through recorded local definitions. Read each line's destination slot in the connection list. Layout columns are presentational. Types and instances remain in the ordered input list; formal type references are a separate relation in the individual application view.

What the cut preserves

Retained and hidden calls partition the explicit call inventory. Internal, incoming, outgoing and hidden uses partition the known source connections. The remaining input positions are counted separately. Expanding a call moves its ports between these classes; collapsing it reverses that change. These are counts of actual application fields, not a disjoint partition of expression subtrees: source fragments can overlap.

The complete compact topology for one profile is loaded within a 2 MiB decoded bound, with at most 128 calls and 1,024 ports. This finite inventory does not establish topology delivery for arbitrary massive corpora. Original expression paths and selected native type graphs retain their existing separate bounds. No original private Lean scripts or tactic histories are included.
